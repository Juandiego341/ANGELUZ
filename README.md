# ANGELUZ 🐾

**ANGELUZ** is a full-stack web application designed to manage pet-related services such as accommodation, grooming, and product sales. The system centralizes client, pet, service, and billing information, providing an efficient solution for businesses offering pet care services.

This project was developed as a real-world oriented system, focusing on clean architecture, role-based access, and practical business logic.

---

## 🚀 Tech Stack

* **Frontend:** HTML5, CSS3, TailwindCSS, Thymeleaf
* **Backend:** Java, Spring Boot, Spring Security
* **Database:** PostgreSQL
* **Authentication:** Role-based access (Admin / User / Moderator)
* **Tools:** Git, GitHub

---

## ✨ Main Features

* User authentication and role management
* Pet registration with detailed health and care information
* Service management (Accommodation, Grooming, Products)
* Check-in and check-out system for pets
* Admin panel for managing services and products
* Total cost calculation (services + products)
* Secure access control by roles

## ⚙️ How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Juandiego341/ANGELUZ.git
   ```

2. Configure the PostgreSQL database and update `application.properties`:

   ```properties
   spring.datasource.url=jdbc:postgresql://localhost:5432/angeluz
   spring.datasource.username=your_user
   spring.datasource.password=your_password
   ```

3. Run the application using your IDE or:

   ```bash
   mvn spring-boot:run
   ```

4. Open your browser at:

   ```
   http://localhost:8080
   ```
